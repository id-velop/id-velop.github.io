Privacy Policy

Last updated: July 29, 2026

Summary: Repository cloning and file writing happen locally on your device. Clone Manager uses ExtensionPay and Stripe only for payment, account sign-in, and license verification.

1. Data Collection

Clone Manager does NOT collect, store, or transmit any of the following:

  • Personal identification information (name, email, address, etc.)
  • Financial information
  • Authentication credentials
  • Personal communications
  • Location data
  • Browsing history or web activity
  • User behavior or activity logs

2. Local Data Processing

All operations are performed locally on your device. The extension:

  • Accesses GitHub and GitLab repository pages to detect clone URLs (HTTPS/SSH)
  • Injects a clone button into the page DOM for user convenience
  • Downloads repository data directly from the Git host you choose
  • Writes repository files only to the folder you select
  • Stores extension preferences, the number of free clone attempts used, and cached paid-access status in browser local storage

3. Permissions Usage

The extension requests the following permissions, each serving a specific purpose:

3.1 Core Permissions

  • storage: Stores user preferences, free-trial usage count, and cached paid-access status locally
  • activeTab: Reads the current tab's URL to pre-fill the clone dialog with repository information
  • scripting: Injects the clone button interface into GitHub and GitLab pages

3.2 Host Permissions

Host permissions are strictly limited to code hosting platforms:

  • https://github.com/*
  • https://gitlab.com/*
  • https://*.gitlab.com/*
  • https://*.gitlab.org/*

These permissions are used solely for:

  • Detecting Git repository clone URLs on repository pages
  • Injecting clone buttons into the page interface
  • Monitoring page navigation changes for single-page applications

4. Third-Party Services

Clone Manager does NOT use analytics or tracking tools.

No companion server is required. When you start a clone, the extension communicates directly with the selected Git hosting service solely to retrieve the repository. The extension:

  • Runs the Git engine inside the browser extension
  • Uses Chrome's native folder picker
  • Does not open Terminal or require you to type commands
  • Writes the cloned repository directly to the folder you select

For optional Pro purchases, Clone Manager uses ExtensionPay for checkout, account sign-in, and paid-license verification. ExtensionPay uses Stripe to process payments. Payment and account information is handled by those providers under their respective privacy policies; Clone Manager does not receive or store your full card details.

5. Data Security

Your selected local folder path is processed on your device and is not sent to Clone Manager, ExtensionPay, or Stripe. Repository network requests are sent directly to the Git hosting service you selected. Payment and license-verification data is transmitted securely to ExtensionPay and Stripe only when required for those features.

6. Children's Privacy

Clone Manager does not knowingly collect any information from children under the age of 13. As the extension does not collect any personal data, this is not applicable.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. We will notify you of any changes by updating the "Last updated" date at the top of this page.
