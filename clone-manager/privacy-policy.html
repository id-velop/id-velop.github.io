Privacy Policy

Last updated: September 11, 2026

Summary: Quick Clone reads repository addresses and handles cloning locally on your device. It does not send your data to the developer, and it does not use analytics, advertising, payments, or tracking services.

1. Information Handled

Quick Clone handles only the information required to provide its repository-cloning features:

  • The URL of the active GitHub or GitLab repository page and its detected HTTPS or SSH clone address
  • The local destination folder selected by the user
  • Extension preferences, including language and preferred clone protocol
  • Local companion settings, including the default clone folder, terminal application, and whether to open the terminal after cloning

Quick Clone does not collect names, email addresses, financial information, authentication credentials, personal communications, location data, advertising identifiers, analytics, or user-activity logs. The developer does not receive or store the repository addresses, local paths, or preferences handled by the extension.

2. Local Data Processing

The extension and the Quick Clone companion process information locally on your device. They:

  • Access GitHub and GitLab repository pages to detect clone URLs (HTTPS/SSH)
  • Inject a clone button into the page DOM for user convenience
  • Send the selected clone address to the local companion through http://127.0.0.1:9456
  • Use the Git installation on your device to retrieve repository data from the Git host you choose
  • Write repository files only to the folder you select
  • Store language and clone-protocol preferences in Chrome local storage
  • Store companion settings in a local configuration file on your device

Clone job status is held temporarily in the companion's memory and is cleared when the companion stops. Quick Clone does not operate a remote server that receives this information.

3. Permissions Usage

The extension requests the following permissions, each serving a specific purpose:

3.1 Core Permissions

  • storage: Stores the selected interface language and HTTPS/SSH clone preference in Chrome local storage
  • activeTab: Reads the current tab's URL to pre-fill the clone dialog with repository information
  • nativeMessaging: Starts and checks the locally installed Quick Clone companion

3.2 Host Permissions

Host permissions are strictly limited to code hosting platforms:

  • https://github.com/*
  • https://gitlab.com/*
  • https://*.gitlab.com/*
  • https://*.gitlab.org/*
  • https://git.garena.com/*
  • https://*.garena.com/*
  • http://127.0.0.1:9456/*

These permissions are used solely for:

  • Detecting Git repository clone URLs on repository pages
  • Injecting clone buttons into the page interface
  • Monitoring page navigation changes for single-page applications
  • Communicating with the Quick Clone companion on the same device

4. Third-Party Services

Quick Clone does not use analytics, advertising, tracking, payment, account, or license-verification services.

Quick Clone requires its local companion to select folders and run Git. When you start a clone:

  • The extension sends the clone address and selected local path only to the companion running on your device
  • The companion opens the operating system's folder picker and runs the locally installed Git command
  • Git connects directly to the selected Git hosting service under that service's privacy policy
  • The companion can open the user's selected terminal application after cloning when that setting is enabled

5. Data Use and Sharing

Quick Clone uses handled information only to provide its user-facing repository-cloning features. It does not sell user data, use it for advertising or creditworthiness, transfer it to data brokers, or permit humans to read it. Information is shared only with the local companion and the Git hosting service selected by the user as necessary to complete a clone.

6. Data Security

The local companion accepts requests only from the registered Quick Clone extension and listens only on the loopback address of your device. Repository network requests are made by your local Git installation directly to the Git hosting service you select. Quick Clone does not send repository addresses, local paths, settings, or repository contents to the developer or unrelated third parties.

7. Storage, Retention, and Deletion

Extension preferences remain in Chrome local storage until you change them, remove the extension, or clear the extension's data. Companion settings remain in its local configuration file until you change them or remove that file. Cloned repositories remain in the folders you selected until you delete them. Quick Clone has no developer-operated copy of this data.

8. Children's Privacy

Quick Clone does not knowingly collect personal information from children under the age of 13.

9. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. We will notify you of any changes by updating the "Last updated" date at the top of this page.
